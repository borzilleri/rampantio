This is Brine Calculator, a tool for calculating how much salt to add to a given amount of water for fermentation.

There should be an input field to input how much water is being used, with a dropdown to select units (gallons, quarts, pints, cups, ml, grams).

There should be a highly visible output calculation, showing the amount of salt to add to create the desired brine ratio. If the input is in an imperial volume measurement (gal, quart, pt, cup), the output should be calculated in cups/tablespoons/teaspoons, otherwise it should be shown in grams.

At the top should be a tab-bar-like selection to choose what kind of brine ratio to use:
* Basic: 3%
* Cucumber: 5%
* Kimchi: 6%
* Manual: Input box for percentage.
